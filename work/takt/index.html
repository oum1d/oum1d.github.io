Tram dispatcher system

A live map where trams move because time moves, not because an animation loops. The dispatcher sees delays build up, opens an incident and watches the line recover.

  • Live map
  • Dashboard
  • Three languages
Open the siteView the code

The problem

A tram dispatcher watches a line all day. When one tram runs late, the gap ahead of it grows and the one behind catches up: a small delay becomes a bunched line within half an hour. Most demo dashboards show a frozen picture and hide exactly this.

What I built

A map where trams move because time moves. Every vehicle has a position calculated from the timetable and its current delay, so the picture at 09:14 is genuinely different from the picture at 09:12. Speed the clock up and you watch a delay spread down the line.

A screen for each person who uses it. The dispatcher sees the whole line; the depot sees which vehicles are out; the driver gets a single phone-sized screen with the next stop and the current gap.

Incidents, not just numbers. Block a stretch of track and the trams behind it behave accordingly — then watch the line recover once it is cleared.

A landing page that sells it. The system sits behind a page aimed at a transport operator: what it solves, what it costs, how a pilot would run.

Three languages

Polish, Ukrainian and English, with the switch keeping you on the same screen rather than sending you back to the home page.
